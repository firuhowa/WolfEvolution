# WolfEvolution
26.3 First-ever Wolf Mod!!
・Fixed an issue where wolves would disappear upon re-entering the world. (java.lang.IllegalArgumentException: Data value id is too big with 25!)
・Improved how wolves are identified, addressing issues caused by UUID mismatches.
・Added a feature to force-report the location of any wolf within 30 blocks to yourself (press the 'h' key).
・Added subtitles for sounds produced when the wolf makes a "blowing" (huffing/puffing) noise.
・Wolves will now lie down if the player is AFK for 1 minute (the AFK status is cleared if the wolf nudges the player).
・Fixed a bug that prevented wolves from being processed correctly on the client side.
